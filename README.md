# eNetViet Pricing

Bản thiết kế tương tác trên mobile cho trang lựa chọn eNetViet Miễn phí và eNetViet Nâng cao.

## Xem bản thiết kế

Mở `index.html` trực tiếp trong trình duyệt. Project là HTML độc lập, không cần cài đặt hoặc build.

File HTML được giữ nguyên từ bản cung cấp, bao gồm iframe sandbox và Content Security Policy (CSP).

## Nội dung

- Áp dụng cho nhiều cấp học.
- Hai lựa chọn: Miễn phí và Nâng cao.
- Mức phí phụ thuộc khu vực hoặc trường; bản thiết kế chưa sử dụng một mức giá cố định.
